# Kandil Real Estate Module for Odoo

## Install
1. Copy this folder to your Odoo `addons` path.
2. Update Apps list and install "Kandil Real Estate".
3. Install dependency: `account` (optional but recommended for payment links).

## Demo data
Load `data/estate_demo.xml` from the module to create sample buildings, units and partners.

## Features
- Buildings, Units
- Reservations (with deposit)
- Contracts (sale & rent)
- Installment schedule
- PDF contract report
